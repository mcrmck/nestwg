# Security policy

`nestwg` is pre-release software and must not yet be relied upon as a security
or anonymity boundary.

## Supported versions

Before the first tagged release, only the current `main` branch receives
security fixes. After releases begin, the latest minor release will receive
security fixes; older pre-1.0 versions may require upgrading.

## Reporting

Report vulnerabilities through the repository's
[private security-advisory interface](https://github.com/mcrmck/nestwg/security/advisories/new)
rather than a public issue. Maintainers aim
to acknowledge a complete report within three business days, provide an
initial assessment within seven days, and coordinate disclosure after a fix is
available. These are response goals rather than a paid support guarantee.

Reports should include the affected commit, reproduction steps, expected
privacy or isolation property, observed behavior, and whether public details
have already been disclosed elsewhere. Never include live VPN private keys,
preshared keys, account tokens, or identifying packet captures.
